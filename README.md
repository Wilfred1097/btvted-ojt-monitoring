# 📊 BTVTEd OJT Monitoring System

The **BTVTEd OJT Monitoring System** is a digital tracking platform built to streamline the monitoring and evaluation of On-the-Job Training (OJT) or Supervised Industry Training (SIT) for **Bachelor of Technical-Vocational Teacher Education (BTVTEd)** students. It helps coordinators, advisers, and trainees manage working hours, task logs, and progress reports efficiently.

🌐 **Live Demo:** [Student Information Survey](https://wilfred1097.github.io/Student_Information_Survey/)

## ✨ Features

- **⏱️ Hours Tracking & Logging:** Easily record and monitor daily completed OJT hours to ensure compliance with curriculum requirements.
- **📝 Task & Activity Reporting:** Document daily accomplishments, duties, and industry experiences.
- **👥 Role-Based Management:** Tailored views/dashboards for students, coordinators, and administrators *(customize based on your implementation)*.
- **📈 Progress Dashboards:** Visual indicators showing total hours rendered versus remaining requirements.
- **📱 Responsive & User-Friendly:** Clean, intuitive UI optimized for both desktop and mobile use.
- **🔒 Secure & Reliable:** Built with modern web technologies for smooth data handling.

## 🚀 Getting Started Locally

To set up and run a local copy of this project:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Wilfred1097/btvted-ojt-monitoring.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd btvted-ojt-monitoring
   ```

3. **Run the project:**
   - Open `index.html` in your favorite web browser or serve it using a local development server.

---

## 💡 How to Use

1. Log in using your designated user credentials (Student or Coordinator).
2. Trainees can input their daily time logs and descriptions of tasks performed.
3. Coordinators can review submitted hours, monitor attendance, and evaluate progress reports.
